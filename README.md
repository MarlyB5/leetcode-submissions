## My Approach

For each problem, I aim to:

1. Understand the input, expected output and constraints.
2. Write a simple working solution.
3. Test the solution using normal and edge cases.
4. Analyse its time and space complexity.
5. Improve the solution when a more efficient approach is available.
6. Keep the final code clear and readable.

## Complexity Analysis

Where possible, I document:

- **Time complexity:** How the running time grows as the input becomes larger.
- **Space complexity:** How much additional memory the solution requires.

Understanding complexity helps me compare different solutions and choose a more efficient approach.
